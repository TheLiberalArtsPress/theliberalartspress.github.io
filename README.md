# 📖 文史哲出版社 — 官方網站與後台管理系統

本專案為 **文史哲出版社（The Liberal Arts Press，創立於1971年）** 之完整靜態官方網站與獨立後台管理系統。

---

## 🌟 系統特色與功能亮點

1. **📚 2,632 冊完整典籍資料庫**：
   - 預先編譯於 `data.js`，包含全館所有書籍（書碼、書名、作者、年份、定價、ISBN、庫存狀態、叢書類別、書籍簡介、心得評析與封面圖）。
   - 開啟網頁 **0 秒延遲**，支援離線與線上多種部署模式。

2. **⚙️ 專業獨立管理後台 (`admin.html`)**：
   - **安全登入驗證**：預設管理員密碼為 `lapen_admin_888`（可在後台自訂修改）。
   - **書籍庫存管理**：
     - 🔍 即時搜尋全館 2,632+ 本書（支援書碼、書名、作者、分類、ISBN 關鍵字篩選）。
     - ➕ **新增書籍**：填寫書碼、書名、作者、年份、分類、定價、庫存、ISBN、簡介與評析。
     - ✏️ **編輯書籍**：修改所有欄位，支援**直接輸入圖片網址**或**從本機上傳圖片（自動轉為 Base64 預覽）**。
     - 🗑️ **刪除書籍**：附防呆確認機制。
     - 📥 **一鍵導出 `data.js`**：後台增修後點擊「一鍵導出」，覆蓋目錄中的 `data.js` 並推送到 GitHub，官方網站即刻全面更新！
   - **🛒 顧客訂單管理**：
     - 串連前台「我的書包」送出的訂單。
     - 完整紀錄收件人、電話、Email、地址、付款方式、購買清單明細與總金額。
     - 支援狀態變更（待處理 / 處理中 / 已出貨 / 已完成 / 已取消）與管理備註。
   - **💬 客服與建議反映**：
     - 串連前台「客服與建議」讀者留言。
     - 即時查看反映內容、稱呼與電話，標記已回覆並填寫回覆紀錄。
   - **🖼️ 首頁輪播圖管理**：自訂首頁焦點形象看板與連結。

3. **☁️ 免費 Google Sheets 雲端資料庫串接 (`backend_gas.js`)**：
   - 附贈完整 Google Apps Script 伺服端原始碼，支援免伺服器 Google 試算表即時讀寫。

## 🚀 快速上手教學

### 1. 本機直接開啟瀏覽與管理

- **前台首頁**：用瀏覽器開啟 `index.html`。
- **管理後台**：用瀏覽器開啟 `admin.html`（或從前台頁尾點擊「管理後台系統」）。
  - **預設密碼**：`lapen_admin_888`

---

### 2. 在 GitHub 免費發佈為公開網站 (GitHub Pages)

本專案已同步至您的 GitHub 倉庫：
🔗 **https://github.com/TheLiberalArtsPress/theliberalartspress.github.io**

1. 前往 GitHub 倉庫的 **Settings** -> **Pages**。
2. 在 **Build and deployment** 下：
   - **Source** 選擇：`Deploy from a branch`
   - **Branch** 選擇：`main` / `/(root)`
   - 點擊 **Save**。
3. 等待 1 分鐘即可透過專屬網址存取：
   🌐 `https://theliberalartspress.github.io/`（官方網站）

---

### 3. 安全管理方式（僅限桌面版 EXE）
為保障網站安全，本專案已**全面撤除線上公開後台網頁**，所有管理操作均透過本機專用的 `文史哲後台管理系統.exe` 進行。

1. 雙擊執行 `文史哲後台管理系統.exe` 登入。
2. 進行書籍、輪播圖或推薦書單的調整。
3. 點擊右上角 **「🚀 一鍵同步更新至 GitHub」**，系統將自動透過加密 API 發佈更新！
4. 將下載的 `data.js` 覆蓋至本專案目錄。
5. 在終端機執行推送到 GitHub：
   ```bash
   git add data.js
   git commit -m "update: 更新書籍資料庫"
   git push
   ```
   網站便會立即呈現最新內容！

---

### 4. (選用) 部署專屬 Google Sheets 即時後端

若您想讓訂單與客服表單即時自動寫入您的 Google 試算表：

1. 打開 Google Drive，建立新的 **Google 試算表**，命名為 `文史哲出版社資料庫`。
2. 點擊上方選單 **擴充功能** -> **Apps Script**。
3. 清空原本內容，將專案中的 **`backend_gas.js`** 全部程式碼複製貼上。
4. 點擊右上角 **部署** -> **新增部署作業**：
   - 類型選「網頁應用程式 (Web App)」。
   - **執行身分**：我。
   - **誰可以存取**：所有人 (Anyone)。
5. 點擊部署並完成 Google 授權，複製取得的 **Web App 網址**。
6. 打開 `admin.html` -> **系統與安全設定**，將網址貼入「GAS API 網址」並儲存即可！
